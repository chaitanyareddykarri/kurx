# Template: Decision Entry

Mirrors the `docs/DECISIONS.md` `D-NNN` format — use this to draft before appending there.

```
## D-NNN · <short title>

**Context**: what was ambiguous or undecided.
**Decision**: what was chosen.
**Why**: the reasoning (constraint, tradeoff, prior incident).
**Alternatives considered**: briefly, if any.
```

Append the filled-in block to `docs/DECISIONS.md` — never keep a decision only in this template or in memory.
